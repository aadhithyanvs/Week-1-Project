# Employee Attrition Data Analysis

## Project Overview
This project analyzes employee data to understand employee attrition patterns using Python, Pandas, NumPy, Matplotlib, and Seaborn.

## Dataset
- Dataset: IBM HR Analytics Employee Attrition
- Records: 1,470 employees
- Columns: 35
- File: `Data/WA_Fn-UseC_-HR-Employee-Attrition.csv`

## Requirements
- Python
- pandas
- numpy
- matplotlib
- seaborn
- ipykernel
- nbconvert

## Setup Instructions

1. Clone the repository.
2. Open the project folder in VS Code.
3. Create a virtual environment:

   `python -m venv .venv`

4. Activate the environment in PowerShell:

   `.venv\Scripts\Activate.ps1`

5. Install the required packages:

   `python -m pip install -r requirements.txt`

## Run the Project

1. Open `notebooks/employee_attrition_anlysis.ipynb` in VS Code.
2. Select the project's Python virtual environment as the notebook kernel.
3. Run the notebook cells from top to bottom.

## Project Outputs

- Cleaned dataset: `Data/clean_data.csv`
- Findings summary: `Reports/findings_summary.md`
- HTML report: `Reports/employee_attrition_analysis.html`
- Charts: `Reports/figures/`

## Project Objective
Identify employee attrition patterns, explore factors associated with attrition, and provide recommendations based on the analysis.
